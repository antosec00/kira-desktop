# Documentazione di Kira Desktop

*[Documentation in English](../en/README.md)*

Kira Desktop è l'applicazione nativa per lavorare con progetti, chat, modelli di
IA, strumenti e team di agenti sul tuo computer. Questa documentazione spiega
come funziona in ogni dettaglio, come usarla al meglio e quali sono i suoi
limiti. È scritta in italiano; la traduzione inglese è in `docs/en/`.
