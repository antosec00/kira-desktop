# Kira Desktop documentation

*[Documentazione in italiano](../it/README.md)*

Kira Desktop is the native application for working with projects, chats, AI
models, tools and agent teams on your computer. This documentation explains
how it works in every detail, how to make the most of it and what its limits
are. It is written in Italian; the English translation is in `docs/en/`.
